Privacy policy

This policy describes Content Studio, a personal-use application operated by Ahmed Khattab. Content Studio uses YouTube API Services. Google’s handling of data is described in the Google Privacy Policy.

Data accessed and purpose

When the operator authorizes a channel, the application obtains OAuth access and refresh tokens and verifies the channel ID. It uses channel and upload-playlist identifiers, video identifiers, publication metadata, processing status and visibility to route uploads, check completion and avoid duplicate publication. Video files, titles, descriptions, tags, category, audience designation and synthetic-media disclosures are sent to YouTube when publishing is requested.

The application can retrieve video statistics for the operator’s publication records. Audience-retention reports require separately enabled functionality and additional authorization. The current shared connection requests the YouTube account-management scope; it does not request access to Gmail, Google Drive or Google Contacts. Although Google describes this scope broadly, the current publisher does not read private messages or implement comment, rating or caption management.

Storage and access

OAuth credentials are stored in an owner-restricted file on the operator’s computer, outside the source repository. Production files, API responses and publication records are stored in the local application workspace and database. Authorized local processes can access this information. The public website and its GitHub repository do not contain channel tokens or private production records.

Sharing and limited use

The application sends authorized requests and video uploads to Google/YouTube to provide publishing features. It does not sell Google user data, use it for advertising targeting, or use it to train generalized AI models. Content Studio’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This public website is hosted by GitHub Pages. GitHub may process ordinary request information, such as IP addresses and browser details, under the GitHub Privacy Statement. The site itself does not add analytics, advertising trackers, cookies or account forms. External links take you to services with their own policies.

Retention, revocation and deletion

Credentials and local application records remain on the operator’s computer until removed. Removing the application does not automatically remove its data files. There is currently no automated retention/deletion service. The operator is responsible for reviewing stored API data, refreshing or removing it as required by YouTube policies, and handling deletion requests.

You can revoke the application’s Google access through Google Account permissions. Revocation stops future authorized API access but does not by itself erase existing local files or videos already uploaded to YouTube. Contact the operator to request removal of stored credentials and associated local API data. Uploaded videos can be managed separately in YouTube Studio.
