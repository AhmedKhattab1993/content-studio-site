Content Studio helps Ahmed Khattab prepare, check and publish original videos across five independently managed channels.

The application runs on the operator’s computer. This website explains the application and its data practices; it is not a hosted editor or a public sign-up service.

Prepare each story

Organize research, scripts, narration, video files and publication metadata in a dedicated workspace for each brand.

Check before release

Track production evidence and validate the intended channel and required episode checks before an upload or release.

Connect the right channel

Use Google OAuth and YouTube API Services to authorize each channel separately, upload videos privately and request public release after checks pass.

Five channels. Distinct identities.

One shared application supports separate channel authorizations, brand settings and publication records.
